Я придумал ЯП, но оказалось, что это НАМ (нормальный алгоритм Маркова)

Этот репозиторий - код интерпретатора и примеры. Код написан на [v](https://github.com/vlang/v)

Пример запуска:
```bash
v run main.v examples/add_bin.rx --input '10+110'
```

### Концепция
Программа на вход получает строку и преобразует эту строку много раз по расписанными правилам, пока либо не встретится терминальное правило, либо строка не перестанет подходить под все правила. Чем раньше в файле правило, тем выше у него приоритет.

### Синтаксис
Программа на этом языке - это список *правил преобразования* строки

*Правило преобразования* состоит из *паттерна* и *результата*:
- *паттерн* - символы алфавита, `*` либо `?`. Похоже на [glob выражения](https://en.wikipedia.org/wiki/Glob_(programming)), но в урезаном виде
- *результат* преобразования - символы алфавита, либо `[n]`, где n - номер подстроки, которая заматчилась `*` или `?`

*Паттерн* и *результат* разделены либо `->`, если это обычное правило, либо `!>`, если при выполнении этого правила следует остановиться

### Исполнение

Исполнение работает так: пытаемся сопоставить текущую строку с паттерном, если получилось - применяем правило, если нет - смотрим на следующее по счету правило и так далее

Программа останавливается в двух случаях:

1. Не нашлось подходящих правил
2. Было применено правило, объявленное с `!>`

### Дополнительно
- В языке поддерживаются комментарии - строки, начинающиеся с '#'
- Допустимы пустые строки. Пример - программа, проверяющая, что строка состоит из символов a
    ```bash
    *a* -> [1][2]
    !> true
    * !> false
    ```


### Примеры
1) Удвоение строки
    ```bash
    * !> [1][1]
    ```
2) Удвоение строки до бесконечности
    ```bash
    * -> [1][1]
    ```
3) Все буквы `a` заменить на `b`
    ```bash
    *a* -> [1]b[2]
    ```
4) Разворот строки
    ```bash
    *?&* -> [1]&[3][2]
    &* !> [1]
    * -> [1]&
    ```

### Тьюринг-полнота
Легко доказать, что этот язык - Тьюринг-полный

- Считаем, что в алфавите МТ нет спецсимволов и нет `<` и `>`
- Состояние машины Тьюринга и позицию бегунка можно кодировать в строке так: `symbols...<state_name><cur_symbol>other_symbols...`
- Обозначим `e` - символ заполнитель бесконечной ленты

Пример начала программы - указываем, что состояние стартовое, ставим бегунок на первый символ:
```bash
# Эти правила - в самом конце программы, чтобы иметь меньший приоритет
?* -> <start_state><?>*
-> <start_state><e>
```

Изменения состояний МТ
Обозначим:
- `c` - текущий символ
- `n` - новый символ
- `cur_state` - текущее состояние
- `new_state` - новое состояние

1) Не надо двигать бегунок:
    ```bash
    *<cur_state><c>* -> [1]<new_state><n>[2]
    ```
2) Надо подвинуть бегунок вправо
    ```bash
    *<cur_state><c>?* -> [1]n<new_state><[2]>[3]
    *<cur_state><c> -> [1]n<new_state><e>
    ```
2) Надо подвинуть бегунок влево
    ```bash
    *?<cur_state><c>* -> [1]<new_state><[2]>n[3]
    <cur_state><c>* -> <new_state><e>n[1]
    ```

Завершение программы и очистка строки от лишних `e`:
```bash
*<halt_state><?>* -> <cleaning>[1][2][3]
<cleaning>*e -> <cleaning>[1]
<cleaning>e* -> <cleaning>[1]
<cleaning>* !> [1]
```
